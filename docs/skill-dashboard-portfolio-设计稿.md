## 1. 项目名称

**Skill Dashboard**  
本地 AI 能力资产管理台 / PM 作品集展示页

---

## 2. 品牌定位

### 当前定义

一个面向非技术背景 AI 工具用户的本地能力资产管理产品，帮助用户把分散的 skills、rules、prompts、instructions 整理成可理解、可检索、可持续治理的能力地图。

### 一句话版本

Skill Dashboard 不是再增加一个 AI 工具，而是帮助用户看清自己已经拥有的 AI 能力。

### 关键词

- 能力地图
- 本地资产
- 产品感
- PM 作品集
- 可治理

### 可改稿区

## 3. 页面目标

### 面向谁

- 产品经理面试官
- 作品集评审者
- 希望快速理解项目价值的人

### 页面要回答的问题

1. 这个项目解决什么问题
2. 为什么这个问题成立
3. 当前 Alpha 做到了什么
4. 产品做了哪些关键取舍
5. 技术结构如何支撑这些承诺

### 可改稿区

```md

- [ ] 问题定义
- [ ] 作品集表达
- [ ] 面试口播
- [ ] 产品结构
- [ ] 技术可信度
```

## 5. 字体系统

### 当前方案

- 标题：`DM Serif Display`
- 正文：`DM Sans`
- 中文回退：`PingFang SC / Microsoft YaHei / Songti SC`

### 字阶

- Hero 标题：`clamp(3rem, 6vw, 5.1rem)`
- Section 标题：`clamp(2rem, 4vw, 2.9rem)`
- 正文：`0.92rem - 1.02rem`
- 标签：`0.74rem - 0.85rem`

### 当前判断

- 标题有作品集气质
- 正文可读性不错
- 中英混排时整体还算稳定

### 可改稿区

```md
字体想改成：
- [ ] 更现代
- [ ] 更品牌感
- [ ] 更出版物感
- [ ] 保持不变
```

## 10. 最终备注

这页现在最需要的不是“增加更多内容”，而是：

- 让内容更精炼
- 让首屏和正文更顺
- 让作品集感再明确一点
